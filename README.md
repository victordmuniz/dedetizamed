# dedetizamed

Site institucional + landing pages de anúncio da dedetizamed (Medianeira-PR).

## Estrutura

- `public/` — código-fonte do site (o que é publicado). Configure o **Root Directory** do projeto na Vercel como `public`.
- `MANUAL DE IDENTIDADE/` — arquivos originais de logo e paleta de cores da marca (referência, não servido pelo site).
- `SPEC.md` — especificação funcional completa do projeto.
- `PRODUCT.md` — contexto de produto (usuários, posicionamento, princípios) usado pelo skill Impeccable.
- `docs/agents/` — convenções para agentes (tracker de issues, labels de triagem, docs de domínio).

## Stack

HTML/CSS/JS puro, sem framework, sem build step. Deploy via Vercel a partir deste repositório GitHub.
